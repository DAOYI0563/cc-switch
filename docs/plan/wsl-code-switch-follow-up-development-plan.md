## 1. 当前基线

- 软件实现、自动化合同、Windows 原生构建和隔离启动烟测已经完成。
- 已有完整能力：三端供应商、MCP、Prompt、本地 Skill、本地扫描与冲突中心、手动 sync-v3、只读会话、CLI 状态和每日简报。
- WebDAV sync-v3 已接通设置页、首次预览、手动同步、设备管理、E2EE、逐记录合并、永久墓碑、ETag CAS 和临时回滚。
- 当前交付物：`dist-portable/WSL-Code-Switch-3.19.4-Windows-x64-portable.exe`。
- 唯一未完成的外部环境验收：使用真实 WebDAV 服务和两台实体 Windows/WSL 设备完成端到端收敛烟测。

## 2. 固定产品边界

后续开发不得改变以下边界：

- 只支持 Windows 11 x64、WSL2 发行版 `Ubuntu`、WSL 用户 `zhldm` 和 Windows Terminal。
- 只管理 Claude Code、Codex、OpenCode。
- 最终只交付便携式 EXE，不生成 MSI、MSIX、NSIS、macOS 或 Linux 桌面包。
- WebDAV 只允许用户手动同步，禁止定时同步、后台重试和 S3。
- WebDAV 使用逐记录双向同步、设备登记、永久墓碑、ETag CAS 和端到端加密。
- 原始会话只读、只在本机使用，永不上传；只有完整且校验通过的每日简报可以加密同步。
- 不恢复代理、协议转换、路由接管、故障转移、统计仪表盘、Profiles、Deep Link、Updater、OMO 和非目标客户端。
- 应用只查询官方 CLI 最新版本并生成可复制命令，不自动安装或执行升级。

## 3. 优先级和快节奏规则

| 级别 | 含义                                   | 执行策略     |
| ---- | -------------------------------------- | ------------ |
| P0   | 影响数据安全、核心可用性或最终交付     | 必须完成     |
| P1   | 用户明确需要，但可在核心版之后增量交付 | 按里程碑完成 |
| P2   | 体验优化或低频边角                     | 不阻塞打包   |

为控制开发时间，采用以下验证规则：

1. 每个任务只跑直接相关的聚焦测试。
2. 每个里程碑结束再跑一次前端、Rust 和 Windows 构建门。
3. 只有数据迁移、WebDAV 写入、凭据、DPAPI 和 WSL UNC 写入必须保留负向测试。
4. 不为未保留功能修复测试；对应代码和测试直接在清场阶段删除。
5. 每个里程碑必须生成一个可启动的便携 EXE，失败则不进入下一阶段。

## 5. M1：手动 WebDAV 完整闭环

### 目标

把已完成的 sync-v3 领域核心接成真正可用的手动同步流程，并彻底关闭旧整包同步、自动同步和 S3。

### 工作项

- [x] **M1-01 删除旧同步活动链路**
  - 删除旧 `db.sql + skills.zip`/归档覆盖协议。
  - 删除 WebDAV 自动同步 worker、启动任务、后台重试、设置和事件。
  - 删除 S3 服务、命令、凭据、设置、UI、测试和依赖。
  - 保留 WebDAV 凭据保存、连接测试和 sync-v3 传输适配器。

- [x] **M1-02 实现 sync-v3 应用编排服务**
  - 串联读取远端、解密、校验、逐记录合并、条件写、一次重合并和本地应用。
  - 远端提交成功后才允许应用本地动作。
  - 错误口令、篡改、非法 manifest、第一次以外的 CAS 竞争均零覆盖停止。
  - 冲突记录进入统一冲突中心，无冲突记录继续同步。

- [x] **M1-03 接入手动命令和设置页**
  - 保留“保存凭据”“测试连接”“首次同步预览”“立即同步”“设备管理”。
  - 首次预览只展示新增、修改、删除和冲突计数，确认前本地与远端零写。
  - 设备退役显示风险确认；同步失败不创建定时重试。
  - 同步口令只在本次操作使用，不写入普通设置或远端。

- [x] **M1-04 完成双运行时设备行为验收**
  - 两台设备分别新增、修改、删除不同记录并双向收敛。
  - 同一记录并发修改进入冲突中心。
  - 第一次 ETag 竞争重新合并一次，第二次竞争安全停止。
  - WebDAV 远端只存在密文，无凭据、设备设置或原始会话。
  - 自动化合同以两个独立运行时覆盖设备行为；真实 WebDAV 与两台实体设备仍列入 M6 环境验收。

### 完成标准

- 只有点击“立即同步”才产生 WebDAV 网络访问。
- 两设备手动双向同步、首次预览、冲突和退役流程可用。
- Phase 6 阶段门通过，并生成新的核心便携 EXE。

  - 禁止 shell 字符串拼接，防止会话路径或 ID 注入参数。
  - 仅启动恢复，不修改原始会话文件。

- [x] **M2-04 CLI 当前版本、最新版本与升级命令**
  - 检测三端当前版本及安装渠道。
  - 只查询官方发布渠道的最新版本。
  - 显示来源、当前/最新版本和一条可复制的升级命令。
  - 应用不得自动执行升级命令。

### 完成标准

- 三端会话可浏览、搜索、查看和恢复，后端没有会话写命令。
- 最新版本查询失败时保留当前版本，并给出可解释状态。
- 生成通过启动烟测的增量便携 EXE。

## 7. M3：每日 AI 工作简报

### 工作项

- [x] **M3-01 调度、日期切分和输入选择**
  - 按北京时间切分自然日，每天 08:00 生成前一天简报。
  - 处理应用未启动、休眠唤醒、跨零点和迟到会话；只补跑缺失或输入已变化的日期。
  - 同一时刻只运行一个简报任务。

- [x] **M3-02 会话筛选、去重和隐私边界**
  - 只读取允许的三端会话文本，生成稳定源指纹。
  - 在请求 AI 前移除密钥、令牌、认证头、凭据和高风险路径信息。
  - 把会话内容视为不可信数据，固定系统提示并禁止工具调用。

- [x] **M3-03 AI 客户端和限额**
  - 使用独立配置的自定义 AI API，不复用三端官方令牌、代理或路由层。
  - 实现 24k 分块、最多 50 次请求、最多 100 万 tokens、总时长最多 300 秒。
  - 仅对可重试错误有限重试；不切换其他模型或密钥。
  - 使用 DPAPI 加密续跑检查点，7 天过期，成功后立即删除且永不上传。

- [x] **M3-04 HTML、完整性和本地页面**
  - 输出到独立简报目录，每日一个离线 HTML 文件。
  - HTML 不含 JavaScript、外链资源或未转义模型输出。
  - 保存状态、输入指纹、内容哈希和完整性校验；失败版本不得标记完成。
  - 页面支持日期浏览、状态、轻量搜索、重新生成和删除。

- [x] **M3-05 接入 sync-v3**
  - 只有完整且完整性校验通过的简报可以作为独立记录加密上传。
  - 原始会话、索引、检查点、AI Key 和模型配置不得进入同步载荷。
  - 删除简报通过墓碑传播，新设备按需下载和解密。

### 完成标准

- 08:00、休眠补跑、手动生成、失败续跑和跨零点测试通过。
- 敏感夹具不会进入 API 请求、HTML、日志或 WebDAV。
- 每日 HTML 可离线打开，并可在多设备间加密同步。

## 11. 里程碑验证命令

聚焦任务先执行相关测试；里程碑结束统一执行：

```bash
pnpm typecheck
pnpm format:check
pnpm test:unit
cargo fmt --check --manifest-path src-tauri/Cargo.toml
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
cargo test --manifest-path src-tauri/Cargo.toml -- --test-threads=1
```

Windows 原生便携版构建：

```powershell
pnpm run build:portable
```

## 12. 暂停点和版本建议
